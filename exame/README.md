# Exame Ortopédico (app)

App de consulta de testes do exame físico ortopédico. Expo SDK 58 + Expo Router.
Planejamento em `../replica/` (recon, arquitetura, design, log de construção).

```bash
npm install
npx expo start          # abre no celular pelo Expo Go, ou aperte "w" para a web
npm test                # regras de evidência e busca
npx tsc --noEmit        # checagem de tipos
```

O modo de desenvolvimento inclui um "Teste de demonstração (dados fictícios)"
para ver as telas com números. Ele não entra na versão final.
