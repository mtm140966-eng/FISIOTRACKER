# Painel do editor

Onde o autor escreve os testes, cadastra os estudos de acurácia e publica o
conteúdo para o app. Next.js 16 + Supabase. Como ligar ao Supabase:
`../replica/backend.md`.

```bash
cp .env.example .env.local   # preencher
npm install
npm run dev                  # http://localhost:3010
npm test                     # validação dos formulários e citação do PubMed
```
